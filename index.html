ABOUT THE PROJECT

Minimalism Meets Robust DOM Architecture.

SmartShop is developed for CSE-3532 (Tools & Technologies for Internet Programming) fulfilling Course Outcome 2 (CO2). Built purely with semantic HTML5, utility-first Tailwind CSS, and reactive Vanilla JavaScript DOM semantics.

Zero heavy external JS frameworks, zero ad-hoc raw CSS files, and 100% responsive client-side state synchronized to browser LocalStorage.
